Panduan Operasional & Diagnostik Teknisi

SOP standar pengoperasian Rinova Pro, diagnosa memori penuh, dan debloating aman.

1

Persiapan Perangkat & Pengaktifan USB Debugging

Sebelum perangkat dapat didiagnosa, opsi USB Debugging harus diaktifkan pada ponsel target:

Samsung (One UI):

Pengaturan > Tentang Ponsel > Informasi Perangkat Lunak > Ketuk Nomor Versi (Build Number) sebanyak 7 kali hingga muncul pesan "Mode pengembang telah diaktifkan". Kembali ke Pengaturan utama > Pilihan Pengembang > Aktifkan Debugging USB.

Xiaomi / Redmi / POCO (HyperOS / MIUI):

Pengaturan > Tentang Telepon > Ketuk Versi OS / Versi MIUI 7 kali. Masuk ke Pengaturan Tambahan > Opsi Pengembang > Aktifkan Debugging USB dan Debugging USB (Setelan Keamanan) jika diperlukan.

Infinix / Tecno / Itel (XOS / HiOS):

Pengaturan > Ponsel Saya > Ketuk Nomor Bentukan 7 kali. Kembali ke Pengaturan > Sistem > Opsi Pengembang > Aktifkan Debugging USB.

Oppo / Realme / Vivo (ColorOS / FuntouchOS):

Pengaturan > Tentang Perangkat > Versi > Ketuk Nomor Kompilasi 7 kali. Masuk ke Pengaturan Tambahan / Sistem > Opsi Pengembang > Aktifkan Debugging USB.

Penting: Saat kabel USB dicolokkan ke PC, perhatikan layar HP. Centang "Selalu izinkan dari komputer ini" lalu tekan Izinkan (Allow) pada prompt RSA Fingerprint.
2

Prosedur Mengatasi Masalah Memori Penuh (Multi-Vector Storage Audit)

Gejala Masalah: Notifikasi "Penyimpanan hampir habis" atau "Penyimpanan penuh 100%" muncul terus-menerus, padahal foto, video, dan aplikasi pengguna berukuran sedikit. Perangkat terasa lambat (throttling), panas, dan aplikasi sering tertutup sendiri (force close).

Penyebab Teknis: Terjadi kebocoran alokasi pada database SQLite Android MediaStore (/data/user/0/com.google.android.providers.media.module/databases/external.db), duplikasi backup harian WhatsApp, atau timbunan Recycle Bin.

Langkah Eksekusi:
  1. Hubungkan HP via USB atau Wireless ADB, lalu pastikan status menunjukkan nama model perangkat.
  2. Buka tab Storage dan tekan Run Full Audit.
  3. Periksa Diagnostic Finding Matrix. Centang sektor yang bernilai anomali (MediaStore bloat, WhatsApp redundant backups, Recycle Bin, dll).
  4. Tekan tombol Execute Remediation.
  5. Sistem akan mengeksekusi pembersihan sektor terpilih dan memicu sinyal pemindaian ulang (MEDIA_SCANNER_SCAN_FILE).
  6. Ruang penyimpanan akan seketika bertambah puluhan gigabyte.
Keterangan Teknis: Buka aplikasi Galeri di HP. Galeri mungkin memerlukan waktu 1–3 menit untuk membangun ulang thumbnail gambar. Seluruh foto, video, dokumen, dan riwayat chat WhatsApp tetap utuh 100% karena yang direset hanyalah file katalog indeks sistem dan backup duplikat usang.
3

Manajemen Paket & Penonaktifan Aplikasi (Packages)

Tab Packages memindai langsung seluruh paket yang terpasang di perangkat target secara dinamis.

Opsi Disable (Disarankan):

Menonaktifkan aplikasi untuk pengguna utama (pm disable-user --user 0). Proses latar belakang berhenti total, menghemat baterai & RAM, dan bisa diaktifkan kembali kapan saja.

Opsi Enable:

Mengaktifkan kembali paket yang sebelumnya berstatus disabled (pm enable). Aplikasi langsung aktif kembali tanpa perlu download ulang.

Opsi Uninstall (User 0):

Mencopot paket dari partisi pengguna (pm uninstall -k --user 0). Hanya gunakan untuk aplikasi pihak ketiga yang membandel. Jangan gunakan pada paket Android Core.

Filter "Suggested": Menampilkan paket yang cocok dengan pola telemetri pabrikan, iklan lockscreen (Glance), downloader latar belakang (Aura/IronSource), dan layanan Facebook background.
4

Penyelesaian Masalah (Troubleshooting)

1. Perangkat Terdeteksi sebagai "UNAUTHORIZED":

Layar HP sedang terkunci atau pengguna belum menekan "Izinkan" pada dialog USB Debugging. Nyalakan layar HP dan tekan Izinkan.

2. Perangkat Sama Sekali Tidak Terbaca di Aplikasi:

Periksa kabel USB (pastikan kabel mendukung transfer data, bukan kabel pengisi daya saja). Cek Device Manager di Windows; jika ada tanda seru kuning pada "Android", instal driver ADB (Universal ADB Driver atau Samsung USB Driver).

3. Koneksi Nirkabel Gagal Terhubung:

Pastikan HP dan PC berada pada frekuensi WiFi / Router yang sama. Perhatikan bahwa port pada langkah pairing berbeda dengan port koneksi utama di halaman depan Debugging Nirkabel.
